# Jurnal World History

Cara pakai: sebut nama video ("Hartmann long-form", "Hartmann Short v7", "Bismarck", "Pegasus"), lalu tanya "kenapa data X penting?". Claude membuka file video itu dan menjawab dari tabelnya.

## Isi tiap entri
| Kolom | Arti |
|---|---|
| Data | angka/klaim persis seperti tampil atau dibacakan |
| Waktu | posisi di video (awal bab; detik persis ada di `longform/spec.json` / `timing.json`) |
| Status | **D** terdokumentasi, **K** klaim/anekdot (diberi penanda), **I** interpretasi (diberi atribusi), **?** belum diverifikasi |
| Sumber | sumber yang dikutip (bukan berarti sudah kubaca langsung, lihat catatan di `longform/source-ledger.md`) |
| Kenapa penting | peran naratif: apa yang dikerjakan data itu untuk penonton |
| Risiko | hal yang bisa salah (klaim, kebijakan, hak cipta) |
